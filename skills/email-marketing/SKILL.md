# Email marketing

Define objetivo, segmento, consentimiento disponible, oferta, remitente, cadencia y mecanismo de baja. No uses Gmail como sustituto automático de una plataforma de campañas masivas.

Para cada mensaje entrega disparador, espera, asunto, preencabezado, cuerpo, CTA y condición de salida. Evita enviar mensajes de compra a quien ya convirtió. Diseña límites de frecuencia y exclusiones.

No inventes listas, testimonios ni datos de resultados. Los borradores pueden prepararse con el alcance solicitado. Antes de enviar o activar una secuencia, debe existir autorización explícita para destinatarios, contenido y alcance; una autorización previa suficiente no requiere repetirse.

Comprueba enlaces y variables con datos sintéticos. Mide entregabilidad, clics y conversiones; interpreta aperturas con cautela. Una automatización necesita pruebas y manejo de errores antes de activarse.
