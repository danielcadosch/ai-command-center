# Curaduría de skills

Empieza por la necesidad concreta y revisa las capacidades ya instaladas. Consulta fuentes oficiales y repositorios originales; popularidad o estrellas no sustituyen inspección.

Para cada candidato identifica mantenedor, licencia, revisión exacta, archivos/scripts, dependencias, permisos, mantenimiento y compatibilidad con el cliente. Distingue una skill documental de un plugin con ejecución o MCP.

Recomienda el conjunto mínimo y señala duplicidades. Instala solo dentro del alcance autorizado; prefiere proyecto frente a global cuando la necesidad sea de un repositorio. No ejecutes instaladores remotos opacos ni instales catálogos enteros por defecto.

Registra procedencia y prueba una tarea representativa. Referencia de descubrimiento: https://github.com/vercel-labs/skills
