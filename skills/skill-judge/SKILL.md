# Evaluación de skills

Revisa descripción y alcance, utilidad de instrucciones, dependencias, procedencia, permisos y verificabilidad. Comprueba que recursos enlazados existan y que la skill no asuma herramientas inexistentes.

Evalúa con ejemplos de activación correcta, no activación y datos incompletos. Para flujos con acciones externas, prueba sin efectos reales salvo que estén autorizados. Evalúa el resultado, no solo el formato.

Entrega hallazgos por severidad con evidencia y corrección concreta. No presentes una puntuación propia como estándar oficial. Distingue fallo observado, riesgo y mejora opcional.
