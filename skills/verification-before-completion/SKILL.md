# Verificación antes de completar

Relaciona cada afirmación con evidencia actual: diff revisado, comando y resultado, estado remoto o comportamiento observado. Elige comprobaciones proporcionales al cambio y a los riesgos concretos.

Ejecuta las verificaciones pertinentes y lee sus salidas completas. Diferencia prueba local, CI, prueba de integración y ejecución real en producción. Una no sustituye automáticamente a otra.

Si hay fallos, corrige o informa el bloqueo específico. No ocultes pruebas sin ejecutar ni uses 'todo listo' para conexiones externas no verificadas. Evita repetir pruebas una vez resuelto el riesgo.
